Start here

Open it on the Dell

Press Super + SpaceSuper is the key with the Windows logo.
Type “Matt Realty Desk”The application should appear at the top of the list.
Press EnterThe Today screen opens in the browser. If it is already open, use Alt + Tab to find it.

If the launcher feels easier

Use the app search every time. You do not need a terminal, a password, or a command to open Realty Desk.

Practice once

A sample task

Situation: You met Jamie Carter at an open house.

Contact: Add Jamie as a Buyer, stage New.

Reminder: “Call Jamie about three-bedroom homes” due tomorrow.

After the call: Add one short note and choose the next follow-up date.

That is the core habit: person → note → next action. The system becomes valuable when every conversation ends with a next date.

Use each morning

My plan for today

Keep client details in Realty Desk. This worksheet is for general priorities. Names, phone numbers, private notes, and appointment details belong in the main app.

Notice repetition first

What should we automate later?

Check anything that would genuinely save time. We should automate a stable routine—not a process that is still changing.

A sensible order

How automation should grow

First: remindersThe computer notices who is due and shows the list.
Then: draftsIt prepares a message, but Matt reviews it.
Later: confirmed actionsVoice requests can create records only after showing exactly what will change.
Recommended boundary: the assistant may organize, remind, search, and draft. A person approves anything that contacts a client or materially changes a record.

Talk instead of type

Voice shortcuts

F9
Hold while speaking, then release to type the words.
Super + Ctrl + X
Start or stop continuous dictation.
Super + Ctrl + M
Start or stop meeting transcription.

Use voice inside contact notes, reminders, campaign drafts, or the Assistant box.

Bring people in

Import contacts

From iPhone: Contacts → Lists → press and hold a list → Export. Move the `.vcf` file to the Dell.

From Excel or PC: Save or export the contacts as a CSV UTF-8 file.

In Realty Desk: Contacts → Import contacts. Select the file and review the count.

Matching phone numbers and email addresses are skipped. Nobody is automatically subscribed to email.

The whole routine

Keep it simple

Morning: open Today and clear the due list. During the day: add each real lead and leave a short note after contact. End of day: make sure every active person has a next follow-up date. Once a week: draft one useful client update and write down anything repetitive.

This guide stores its worksheet only in this browser. Realty Desk stores the real contact records and backs them up nightly.
