Helpful additions for Matt's HP

These are optional additions to Omarchy. Matt can review what each one does here; the agent handles installation, verification, and removal.

4Recommended now
4Owner tools or later
4Skip on this HP
Plugins are trusted software. Omarchy plugins run as unsandboxed code with access to Matt's user account. Nothing on this page installs software; Josh or the agent reviews each source and installs one at a time.

Install now

Four additions that reduce hunting, memorizing, and missed information.

Omaplug

Install now

A clearer control panel for Josh and the agent to review, update, disable, or remove plugins.

Matt does not need to manage it. Bulk updates are applied only after every included diff has been reviewed.

Omaplug source and attribution

Which Key

Install now

Hold the Windows key to see the shortcuts that are available right now.

This is the best learning aid in the group because it removes the need to memorize Omarchy all at once.

Which Key source and attribution

Expose

Install now

Shows every open window in one visual overview, similar to Mission Control on a Mac.

Matt can find the CRM, email, or another window without understanding workspace numbers.

Expose source and attribution

Notification Center

Install now

Keeps notifications available after the temporary popup disappears.

The simpler notification history was chosen instead of Omapager's replacement notification system.

Notification Center source and attribution

Owner tools or later

Useful in the right situation, but not part of Matt's first setup.

OmaSettings

Owner tool

Puts many Omarchy settings into one searchable window.

It can edit important configuration, so it is best reserved for Josh or the agent after remote support is working.

OmaSettings source and attribution

Better Bluetooth

If needed

Pins favorite Bluetooth devices and reconnects them after sleep.

Install only if Matt regularly uses Bluetooth headphones, a mouse, or another device that fails to reconnect.

Better Bluetooth source and attribution

Omarchy Tray

If needed

Moves extra bar widgets into a slide-out drawer.

Add it only if the four recommended plugins make the top bar feel crowded; it also needs a separate tray-replacement step.

Omarchy Tray source and attribution

Decent Workspaces

Maybe later

Makes workspace numbers more informative by adding application icons.

Expose is the easier first choice. Revisit this only after Matt is comfortable with Omarchy workspaces.

Decent Workspaces source and attribution

Skip for this setup

These overlap the selected tools, add a more advanced interaction model, or do not support this computer.

Omapager

Do not combine

A capable replacement notification system with grouping, snoozing, and replies.

It overlaps Notification Center and introduces more configuration and optional phone-integration dependencies.

Omapager source and attribution

Vimarchy

Skip for Matt

Adds Vim-style keyboard hints and window actions.

It is aimed at advanced keyboard users and would give Matt another control system to learn.

Vimarchy source and attribution

Omaland

Skip initially

Provides live visual customization for gaps, borders, opacity, and other Hyprland styling.

It does not improve Matt's daily CRM workflow and creates more settings that can be changed accidentally.

Omaland source and attribution

Omdrop

Not for this HP

Adds AirDrop support to Apple Silicon Macs running Omarchy.

Matt's HP is not Apple Silicon. This plugin requires a specialized wireless driver and elevated setup, so it is incompatible with this machine.

Omdrop source and attribution
Owner details

Omarchy already includes plugin management under Setup > Plugins and the omarchy plugin command. The separate owner runbook records the reviewed Git revisions, backups, four approved commands, verification, and rollback steps.
